### 1.4 `suggestedAction` 분리 (§2.4) — **수용**

Codex 권장이 정확하다. 액션과 상태를 섞으면 후속 자동화가 분기 조건을 잘못 잡는다. 분리 채택.

```ts
type JudgeStatus =
  | 'ok'            // 정상 평가
  | 'unstable'      // 재현성 분산 > 0.5
  | 'mixed-model'   // 한 fixture 안에서 모델 fallback 발생
  | 'failed'        // 평가 자체 실패 (응답 없음, 파싱 실패 등)

type SuggestedAction =
  | 'acceptable'              // 점수 양호, 그대로 진행
  | 'design-polish-needed'    // 점수 2점 이하, 자동 고도화 입력
  | 'manual-review-needed'    // 신뢰도 의심, 사람 판단 필요 (judgeStatus가 ok 아닐 때 기본)
  | 'export-blocking'         // 익스포트 단계 hard fail
```

해석 원칙:
- `judgeStatus`는 점수 신뢰도 판단용
- `suggestedAction`은 제품 다음 행동 분기용
- `judgeStatus !== 'ok'`면 `suggestedAction`은 기본 `manual-review-needed`로 강제

라운드 3 §3.3에 박은 enum은 무효화되고 본 분리안이 새 표준.
