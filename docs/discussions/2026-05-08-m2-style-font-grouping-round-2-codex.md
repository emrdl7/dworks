## 2. 추가 범위

사용자 불편:

- 같은 패밀리의 Regular / Medium / Bold 등 여러 TTF/OTF를 한 번에 올릴 수 없어 반복 작업이 많다.
- 현재 단일 파일 기준 prompt가 여러 번 반복되면 디자이너 흐름이 끊긴다.

이번 보강 범위:

- 글꼴 업로드 input에 `multiple` 허용.
- 단일 파일 업로드는 기존처럼 표시명 prompt 유지.
- 여러 파일 업로드는 파일명 기반 표시명/패밀리/굵기 추론으로 일괄 등록하고 prompt 반복을 피한다.
- 성공한 글꼴은 기존 family/weight grouping 로직으로 즉시 묶는다.
- 일부 파일 실패 시 성공분은 유지하고 실패 개수만 사용자 메시지에 표시한다.
- 업로드 후 현재 텍스트 노드는 기본 굵기와 가장 가까운 등록 글꼴을 자동 선택한다.
