## 1. 원인

다중 업로드에서 같은 `familyId + weight` 조합을 중복으로 보고 기존 파일을 새 파일로 교체하도록 구현했다. 그런데 현재 typography weight 스키마가 `400/500/600/700` 네 단계뿐이라, 9개 weight 파일이 네 버킷으로 접혔다.

예상되는 접힘:
- Thin / ExtraLight / Light / Regular → 400 근처
- Medium → 500
- SemiBold → 600
- Bold / ExtraBold / Black → 700

결과적으로 사용자가 9개를 올려도 같은 패밀리 안에서 최대 4개만 남는다.

## 2. 수정 범위

- `FontWeight`를 CSS 표준 weight 단계 `100~900`으로 확장한다.
- 파일명 기반 weight 추론도 100/200/300/400/500/600/700/800/900으로 세분화한다.
- 같은 패밀리+같은 weight일 때만 교체하고, weight 미분류 파일은 임의 교체하지 않는다.
- 타이포그래피 UI의 굵기 옵션도 9단계로 확장한다.
- 기존 400/500/600/700 데이터는 그대로 유효하다.
- 등록 글꼴 목록은 패밀리 그룹 단위로 보여주고, 그룹 전체 삭제 버튼을 추가한다.
- 그룹 삭제 시 해당 패밀리의 모든 weight 파일을 삭제하고 사용 중인 노드 수를 확인 메시지에 포함한다.

## 3. 미해결

- 실제 font name table 파싱은 여전히 후속 `m2-style-font-meta-extract` 범위다.
