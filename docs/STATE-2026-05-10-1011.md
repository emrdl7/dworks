## 코덱스 follow-up (`64d36a7` 2026-05-10 10:10 KST)

> "디자인 모델 source of truth 점검"

### 핵심 비판 (아키텍처)

내 `EffectiveCanvasStyle` 접근은 _DOM 역측정 band-aid_. 정답은 _공유 resolved design model_:

```
raw TreeNode + node type defaults + role defaults + theme tokens + viewport rules + explicit overrides
  → ResolvedNodeDesign
  → 캔버스 / 인스펙터 / 내보내기 / QA가 같은 모델을 본다
```

### 구체 P0 (확인된 버그 3건)

1. **Zoom 나누기 버그** — `getComputedStyle` 픽셀은 CSS px 기준이라 zoom 보정 대상 아님.
   - 200% 줌에서 padding 48 → 인스펙터에 24 (절반) 표시.
   - fix: `useEffect`의 px 함수에서 `/ z` 제거 (1줄).

2. **Layout 토글이 effective 무시** — `effectiveStyle.display/flexDirection/justify/align` 수집해놓고 `LayoutControls`의 toggle selected 상태는 `node.layout`만 본다. 캔버스 grid 렌더가 토글에 안 비침.

3. **더블클릭 콘텐츠 탭 전환 누락** — 사용자가 디자인 탭에 있을 때 텍스트 노드 더블클릭하면 콘텐츠 textarea 못 찾고 색상 hex input 같은 잘못된 input으로 focus.

### 권장 순서

1. 즉시 핫픽스 (위 P0 3건)
2. `effectiveStyle` 확장 멈추고 `resolveNodeDesign()` 도입
3. CanvasNode className → resolver default로 추출
4. AI 생성 후 `normalizeDesignTree()` 정규화

### Acceptance criteria (resolver 기준 통과 조건)

1. 새 hero 선택 시 background, text color, padding, gap, layout mode가 인스펙터-캔버스 일치
2. 100/150/200% 줌에서 인스펙터 수치 변하지 않음
3. mobile/tablet/desktop 전환 시 viewport별 resolved 값 + source 표시
4. reset → 빈 값 X, resolved default로 회귀
5. export/import idempotent
6. className 변경 시 resolver test 깨져서 default drift 잡힘
