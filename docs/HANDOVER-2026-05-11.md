## 미해결 — 사용자 비판 잔여

### 1. 반응형 — viewport별 수치 override (수치 + 컨텐츠 swap)

현재 `hideOn`만 구현. 사용자 표현: "각각 사이즈라던가 border-radius라던가 각각 수치를 지정하거나 안보이게 하거나 이미지 대신 텍스트 들어가거나".

다음 구현 방향:

**A. viewport별 수치 override (스타일 prop)**
- schema: 각 prop slot에 _mobile/tablet override_ 추가. 가장 단순 방법:
  ```ts
  // BaseNodeMeta에:
  responsiveStyle?: {
    mobile?: { spacing?, shape?, color?, layout?, typography?, transform? }
    tablet?: { ... }
    // desktop은 default (root prop이 desktop 의도)
  }
  ```
- design-resolver: viewport에 따라 root prop + responsiveStyle[viewport] merge.
- 인스펙터: 각 prop 영역에 _mobile/tablet 탭_ 추가. 또는 _viewport 전환 토글_ (현재 viewport에 따라 인스펙터에 보이는 값이 다름).
- prompt 가이드: 사용 예시 + AI가 활용하도록 강제.

**B. viewport별 컨텐츠 swap**
- text 노드: `responsiveContent: { mobile?: string, tablet?: string }`
- image 노드: `responsiveSrc: { mobile?: string, ... }`
- 노드 type 변경 (이미지 → 텍스트)은 schema 한계. 같은 위치에 _두 노드_ 배치하고 viewport별 hideOn으로 분기 (현재 가능한 방법).

**C. 인스펙터 viewport-aware**
- 현재 viewport switcher가 캔버스 너비만 변경. 인스펙터 입력 필드는 _현재 viewport의 값_을 보여주고 _override_가 가능해야.
- 작업 큼: 각 ControlsProps에 viewport prop + 입력 onChange가 _root vs responsive_ 분기.

### 2. 인터랙티브 컴포넌트 (carousel / slider / tabs / accordion / modal)

사용자 표현: "이미지 슬라이더 등 다양한 웹 기술들이 있는데... 그런거는 언제쯤 추가할껀데?"

다음 구현 방향 (1개씩 점진):

- **이미지 carousel** (가장 시각 임팩트 큰 것 우선):
  - schema: 새 노드 type `'carousel'` + `images: ImageNode[]` + `auto?: boolean` + `interval?: number`
  - 캔버스 렌더: 정적 미리보기 (첫 이미지 + dot indicator). _실제_ slide 동작은 export 결과에서 (Embla Carousel 등 라이브러리).
  - 인스펙터: 이미지 추가/삭제/순서 변경 + auto/interval prop.
  - 4-6 hour 작업 추정.

- **tabs**: 상위 노드 + tab buttons + tab panels. 캔버스에서 _첫 panel_만 보여주는 정적.
- **accordion**: 비슷한 구조.
- **modal/dialog**: position fixed + backdrop. 캔버스에서 _열린 상태_로 시각만.

### 3. dark-luxury-hero 외 fixture에 overlay 시연 부재

현재 `position`/`inset` 사용 fixture는 `dark-luxury-hero` 1개만. 다른 fixture (예: `playful-product`나 `saas-dashboard`)에도 sticky banner나 floating CTA 패턴 적용해 _가능성_을 더 보여줄 수 있음.

### 4. 인스펙터에 position/inset 노출 X

현재 schema에 추가됐지만 인스펙터 UI는 미구현. 사용자가 GUI에서 overlay 패턴 만들려면 _JSON 직접 편집_ 필요. 인스펙터 _레이아웃 탭_에 _position_ 영역 추가 필요.
