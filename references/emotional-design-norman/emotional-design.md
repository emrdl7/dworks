# Emotional Design Reference

## Three Levels

### Visceral

Immediate first impression before detailed reasoning. It is shaped by color, contrast, scale, image tone, motion, density, and composition.

Good web cues:
- A clear focal point in the first viewport
- A color temperature that matches the service emotion
- Typography with enough contrast between headline, body, and metadata
- Imagery or visual slots that reveal the actual product, place, service, or state

Risks:
- Generic gradients, vague stock mood, oversized copy with no service signal
- Decoration that competes with the primary task

### Behavioral

The feeling created while using the interface. It depends on task clarity, feedback, predictable controls, and low effort.

Good web cues:
- Primary action is obvious and reachable
- Form/list/table patterns match the expected workflow
- States are visible: hover, focus, disabled, loading, error
- Copy explains what happens next

Risks:
- Pretty layouts that hide the task
- Dense information without grouping
- Ambiguous buttons or card actions

### Reflective

The meaning users attach after understanding the service. It depends on trust, identity, pride, memory, and the story the interface tells.

Good web cues:
- Brand, institution, or service purpose is visible early
- Metrics, proof, policies, testimonials, or process details support confidence
- The page explains why the service matters, not only what it does

Risks:
- A polished but interchangeable SaaS look
- No connection between visual mood and actual service value

## Emotional Presets

- Trust and safety: stable grid, deeper brand contrast, proof points, clear process, restrained motion.
- Warmth: softer surfaces, human copy, gentle color temperature, helpful empty/error states.
- Energy: stronger scale changes, event-like rhythm, vivid accents, fast scanning sections.
- Premium calm: generous whitespace, fewer elements, strong typography, quiet surfaces, precise details.
- Competence: dense but organized layout, metrics, table/list clarity, confident neutral palette.
- Care: accessible scale, reassuring microcopy, step-by-step flow, visible help.

## Rule

Emotion is not decoration. Each emotional cue must support first impression, task confidence, or lasting meaning.
