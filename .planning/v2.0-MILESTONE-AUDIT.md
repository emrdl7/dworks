## Tech Debt (3 items)

### 1. UX-06 Quick-add 4 키 silent no-op
- **Location:** `apps/web/src/app/use-quick-add.ts:130-132`
- **Issue:** `A` (accordion), `M` (modal), `Shift+C` (carousel), `Shift+T` (tabs) 키가 cheatsheet 에 advertised 되지만 tree-editor 의 `addContainerChild` signature 가 `'section' | 'hero' | 'card' | 'list' | 'form'` 만 지원해 4 키 silent no-op.
- **Root cause:** carousel/tabs/accordion/modal 은 `items[]` 배열 스키마 (slides/tabs/entries) 로 별도 구조 — quick-add 의 단일-노드-빈-슬롯 추가가 schema-invalid (`min(1)` 위반).
- **Impact:** ROADMAP 명시 "T/B/I/R/C 등 작동" 5 example 키 + H/L/F = 8/12 = 67% 작동.
- **Future fix:** tree-editor `addCarouselSlide` / `addTabsTab` / `addAccordionEntry` / `addModal` helper 추가 → quick-add 자동 활성화 (hook 키매핑은 이미 12개 등록됨).

### 2. VIS-01 Snap-to-column drag commit site deferred
- **Location:** `apps/web/src/app/grid-overlay.tsx` (helpers export + state + 가이드 div)
- **Issue:** snap-to-column 알고리즘 + 가이드 라인 시각화 인프라 박혀 있으나 _자유위치 드래그_ commit site 부재. 현재 codebase 의 PositionControls 는 inspector number fields 만 노출, drag-to-position 기능 없음.
- **Impact:** Phase 1 SUMMARY 의 Rule 3 Scope Boundary deviation 으로 명시 — Phase 3 verifier override 로 accepted.
- **Future fix:** 자유위치 drag 기능 신규 phase 도입 시 1-line `setSnapGuideX(snapped.edge)` 추가로 활성화.

### 3. Phase 5 인스펙터 color picker 통합 deferred
- **Location:** `apps/web/src/app/inspector-atoms.tsx` (현재 단일 색 input 만)
- **Issue:** CONTEXT D-08 "인스펙터 color picker 에 '내 palette' 섹션 추가" 의 dialog 자체는 완성, 인스펙터와의 통합은 v3+ deferred.
