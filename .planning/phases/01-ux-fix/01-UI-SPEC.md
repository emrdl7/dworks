# Phase 1 — UI Design Contract: UX 핵심 fix + 측정 도구

> Visual and interaction contract for UX-02..UX-06 (UX-01 이미 완료). Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Korean UI mandatory** — 모든 사용자 노출 라벨/툴팁/toast/메뉴 한국어.
> **재사용 전제** — chrome dark UI는 `globals.css`의 `--dw-*` 토큰을 _재사용_ 한다. 본 contract는 v1 토큰을 명문화 + Phase 1 전용 새 surface(spacing overlay / 박스 선택 / 좌측 패널 / type-convert dropdown)만 추가 명세한다.

## Spacing Scale

기존 `--dw-space-*` 토큰 _그대로 재사용_. Multiples of 4 (Figma 표준 4pt grid).

| Token | Value | Usage in Phase 1 |
|-------|-------|------------------|
| `--dw-space-1` | 4px | spacing-overlay px 라벨 padding, 컴포넌트 카드 thumbnail border, 정렬 가이드 점선 dash 간격 |
| `--dw-space-2` | 8px | 컴포넌트 패널 카드 grid gap, 변환 dropdown 항목 padding, 박스 선택 inset 표시 |
| `--dw-space-3` | 12px | 좌측 패널 카테고리 header padding, dropdown 항목 left/right padding |
| `--dw-space-4` | 16px | 좌측 패널 좌우 padding (16px = `--dw-space-4`), 카드 내부 padding |
| `--dw-space-5` | 20px | 컴포넌트 카드 thumbnail 영역 height (60px = `--dw-space-5` × 3) |
| `--dw-space-6` | 24px | 카테고리 (Basic / Patterns) 사이 vertical gap |
| `--dw-space-7` | 32px | 좌측 패널 collapsed 상태 width (32px rail) |
| `--dw-space-8` | 40px | 컴포넌트 카드 height (basic node tile) |

**Phase 1 exceptions:**
- 좌측 컴포넌트 라이브러리 패널 width: **240px** (D-08 잠금, 기존 `--dw-left-panel` 변수가 260px이지만 Phase 1은 240px override). 새 변수 `--dw-component-panel-width: 240px` 추가.
- 좌측 패널 collapsed rail width: **32px** (토글 단축키 `[` 후 표시되는 vertical strip).
- Spacing overlay px 라벨 박스 최소 너비: **24px** (값 표시 가독성). height 16px.

## Typography

기존 `--dw-text-*` + `--dw-font-weight-*` 토큰 _그대로 재사용_. Pretendard Variable로 한국어/숫자 모두 처리.

| Role | Size | Weight | Line Height | Phase 1 사용처 |
|------|------|--------|-------------|----------------|
| Section heading | 12px (`--dw-text-section-heading`) | 600 (`--dw-font-weight-label`) | 1.4 | 좌측 패널 카테고리 헤더 ("기본 노드", "패턴"), 변환 서브메뉴 헤더 ("노드 타입 변경") |
| Label | 11px (`--dw-text-label`) | 600 | 1.4 | 컴포넌트 카드 라벨 ("텍스트", "버튼" 등), 단축키 hint badge ("T", "B"), 정렬 toolbar 라벨 |
| Value / Body | 13px (`--dw-text-value`) | 400 (`--dw-font-weight-value`) | 1.5 | toast 본문, dropdown 항목 텍스트, 변환 매트릭스 호환 항목 라벨 |
| Caption | 11px (`--dw-text-caption`) | 400 | 1.4 | spacing overlay px 숫자 라벨 ("16", "24"), 단축키 cheatsheet 보조 설명, 비호환 변환 비활성 항목 hint |

**Spacing overlay 라벨은 monospace 변형 사용:**
- font-family: `ui-monospace, SFMono-Regular, "SF Mono", Menlo, Consolas, monospace`
- font-size: 11px (`--dw-text-caption`)
- font-weight: 600 (정렬된 폭으로 빠른 읽기)
- font-variant-numeric: `tabular-nums` (px 값 변경 시 흔들림 방지)

## Color

기존 `--dw-ui-*` 토큰 _그대로 재사용_. 60/30/10 분배는 chrome 전반에 이미 잠겨 있다. Phase 1은 _Spacing overlay_, _박스 선택_, _정렬 가이드 라인_ 등 새 시각 요소의 색만 추가 정의.

| Role | Token / Value | Usage in Phase 1 |
|------|---------------|------------------|
| Dominant (60%) | `--dw-ui-bg` (#0d0e10) | 캔버스 배경, 좌측 패널 배경 위 가장 어두운 영역 |
| Secondary (30%) | `--dw-ui-panel` (#16181c), `--dw-ui-elevated` (#1d2025) | 좌측 컴포넌트 패널 surface, 변환 dropdown 배경, 컴포넌트 카드 surface |
| Accent (10%) | `--dw-ui-accent` (#6366f1 indigo) | **다음 element에만**: (1) 박스 선택 사각형 border + 반투명 채움, (2) 다중 선택된 노드의 outline, (3) 컴포넌트 카드 hover ring, (4) ⌘K 명령 팔레트 선택 행, (5) 단축키 hint badge 배경 |
| Destructive | `--dw-ui-danger-text` (#fca5a5) + `--dw-ui-danger-bg` (#3a1717) | 비호환 변환 시 경고 toast, 정렬 skip 경고 toast |
| Warning | `--dw-ui-warn-text` (#fbbf24) + `--dw-ui-warn-bg` (#3a2e0a) | 변환 시 프로퍼티 손실 안내 toast (D-07) |

**Phase 1 전용 새 색 (chrome 전반에는 사용 금지, 본 phase 시각 요소 한정):**

| Element | Color | Rationale |
|---------|-------|-----------|
| Spacing overlay 측정 라인 | `#6366f1` (accent 동색) at 80% opacity | indigo와 어우러져 chrome 일관성 유지 |
| Spacing overlay px 라벨 박스 | bg `#6366f1`, text `#ffffff` | 캔버스 위 강조 (라벨 가독성) |
| 정렬 가이드 점선 (snap) | `#FF8FAB` (Figma 파스텔 핑크) | D-03 + Claude discretion. dashed 1px, opacity 90%. _spacing 측정선 (indigo) 과 시각 구분_ |
| 박스 선택 사각형 | border `#6366f1` at 50%, fill `#6366f1` at 10% | D-13 (semantic match — 선택은 accent) |
| 다중 선택 노드 outline | `#6366f1` (accent) 2px solid | 단일 선택과 동일색, 두께만 차이 (단일은 2px → 다중도 2px이지만 모든 selected 노드에 적용) |
| 단축키 hint badge | bg `--dw-ui-accent-soft` (#1e1f3a), text `--dw-ui-accent-text` (#a5b4fc), border `--dw-ui-accent-border` (#4338ca) | 키 라벨 ("T", "B", "Alt+H") 의 visual chip |

**Accent reserved for:** 다중 선택 시각화 + 박스 선택 + 컴포넌트 카드 hover ring + 변환 dropdown 선택 행 + 단축키 hint badge + ⌘K 선택 행. **이 외 어떤 요소도 indigo 사용 금지** (chrome 일관성).

## Interaction Contract (Phase 1 핵심)

본 phase는 _시각 contract_ 보다 _인터랙션 contract_ 가 핵심이다. 아래 항목은 executor가 그대로 구현한다.

### UX-02 — Spacing overlay + 정렬 가이드

| 상태 | 동작 |
|------|------|
| 노드 1개 선택 + 다른 노드 hover | 두 노드 사이 spacing(px) overlay _자동_ 표시. modifier 키 없음 (D-01 — Figma 동등). |
| Alt 누른 채 hover | 위 + _정렬 가이드 점선_ (`#FF8FAB`) 두 노드의 정렬되는 edge 강제 표시. snap 표시는 dashed 1px. |
| 두 노드 겹치지 않음 | 수평 gap + 수직 gap _양쪽_ 표시 (4방향 모두 측정값 라벨). |
| 두 노드 겹침 | inset (top/right/bottom/left) 4방향 px 표시 (D-03). |
| 정렬 edge 발견 (좌/중/우 / 상/중/하 정렬) | 정렬 가이드 점선 표시 — 그 축에서 두 노드가 같은 위치임을 시각화. |
| hover 해제 | overlay 100ms fade-out (`--dw-motion-fast` 80ms 보다 약간 길게 — 화면 깜빡임 방지). |

**렌더 디테일:**
- 캔버스 위 `position: absolute` DOM 레이어. `z-index: 100` (selectable-node outline은 50, modal은 1000).
- 캔버스 zoom/pan transform _곱해서_ 좌표 계산 (canvas-contexts.ts의 transform state 사용).
- 측정선은 두께 1px, color `#6366f1cc` (accent 80% opacity). 끝 마커는 짧은 cap 4px.
- px 라벨 박스는 측정선 _중앙_ + 위쪽 6px 띄움. 라벨이 측정선 한쪽 끝이면 안쪽으로 align.
- 단위 _px만_ (D-04). 소수점 둘째 자리 반올림 (`Math.round(value * 100) / 100`).

### UX-03 — 노드 타입 변환

3-route 진입 (D-05):

| Route | UX |
|-------|-----|
| 컨텍스트 메뉴 (우클릭) | "노드 타입 변경 →" submenu. 호환 type만 enable, 비호환은 _grey + tooltip "변환 불가: {이유}"_ |
| 인스펙터 상단 type dropdown | 노드 선택 시 인스펙터 헤더 부근 dropdown — 현재 type 표시 + 호환 type 목록. 변환 후 인스펙터 즉시 새 type field 렌더. |
| ⌘K 명령 팔레트 | "변환: {target type}" 형식 액션 (예: "변환: 버튼으로", "변환: 캐러셀로"). 현재 노드의 호환 type만 노출. |

**호환 매트릭스 (D-06) — 한국어 라벨:**

| From | To | 매핑 |
|------|----|----|
| text | button | text.content → button.label |
| button | text | button.label → text.content (onClick 손실 → 경고 toast) |
| section | hero | children + spacing 유지 |
| section | card | children + spacing 유지 |
| hero | section | hero.title/subtitle 자식으로 보존 |
| hero | card | hero.image → card.image, hero.title → card.title |
| card | section | card.title 노드로 보존, card.image 제거 (경고 toast) |
| card | hero | card.title → hero.title |
| list | accordion | list.items[] → accordion.entries[] (title 자동 생성: "항목 N") |
| accordion | list | accordion.entries.title → list.items[] (body 손실 → 경고 toast) |
| image | carousel | image → carousel.slides[0] |
| carousel | image | carousel.slides[0] → image (slide 2+ 손실 → 경고 toast) |

**비호환:** form ↔ 다른 type, modal ↔ container 외 type, leaf ↔ container 등. _메뉴에서는 비활성_ + tooltip "변환 불가: {이유}" — 예시 문구:
- "변환 불가: 입력 폼은 다른 노드로 변환할 수 없습니다"
- "변환 불가: 모달은 컨테이너 전용입니다"

**프로퍼티 손실 toast 문구 (Claude discretion, 한국어):**
- onClick 손실: `"버튼의 클릭 동작이 텍스트로 변환되며 사라졌습니다."`
- carousel slide 2+ 손실: `"이미지로 변환되며 첫 슬라이드만 유지되었습니다 (남은 {N}개 슬라이드 제거)."`
- accordion body 손실: `"리스트로 변환되며 각 항목의 본문은 제거되었습니다."`
- card.image 손실: `"섹션으로 변환되며 이미지가 제거되었습니다."`

### UX-05 — 박스 선택 + 정렬/분포

| Action | Trigger | Detail |
|--------|---------|--------|
| 박스 선택 시작 | 캔버스 _빈 공간_ 에서 `Shift+drag` (D-12) | Cmd/⌘+drag은 OS 충돌 회피 — 사용 금지. |
| 박스 시각화 | border `#6366f1` 50% opacity 1px, fill `#6366f1` 10% (D-13) | `pointer-events: none`. z-index 200 (overlay 위). |
| 선택 모드 | _intersect-mode_ (박스 안에 일부라도 들어간 노드 모두 selected) | enclose-mode 아님 — Figma/Webflow 표준. |
| 정렬 좌 | `Alt+A` | 공통 부모 안 selected 노드 left edge → 가장 왼쪽 노드 기준 |
| 정렬 중(가로) | `Alt+H` | horizontal center |
| 정렬 우 | `Alt+D` | right edge |
| 정렬 상 | `Alt+W` | top edge |
| 정렬 중(세로) | `Alt+V` | vertical center |
| 정렬 하 | `Alt+S` | bottom edge |
| 분포 가로 균등 | `Alt+Shift+H` (≥3 노드) | leftmost/rightmost 고정, 사이 균등 |
| 분포 세로 균등 | `Alt+Shift+V` (≥3 노드) | topmost/bottommost 고정, 사이 균등 |

**경고 toast (D-16, 한국어):**
- 자식 layout 이 absolute 아닐 때: `"정렬은 절대 위치(position: absolute) 노드에만 적용됩니다."`
- ≥2 선택이 아닐 때: `"정렬에는 2개 이상의 노드 선택이 필요합니다."`
- ≥3 선택이 아닐 때 (분포): `"분포에는 3개 이상의 노드 선택이 필요합니다."`

### UX-06 — Quick-add 단축키

| Key | Node type | Korean label |
|-----|-----------|-------------|
| `T` | text | 텍스트 |
| `B` | button | 버튼 |
| `I` | image | 이미지 |
| `R` | section | 섹션 (rectangle 연상) |

| `H` | hero | 히어로 |
| `L` | list | 리스트 |

| `A` | accordion | 아코디언 |
| `M` | modal | 모달 |
| `Shift+C` | carousel | 캐러셀 (C가 card와 충돌) |
| `Shift+T` | tabs | 탭 (T가 text와 충돌) |

**활성 조건 (D-17):** 캔버스 포커스 + 텍스트 입력 아님 + 모달/⌘K 팔레트 닫혀 있을 때. 기존 `command-palette.tsx` 의 활성 가드 패턴 재사용.

**추가 위치 (D-18):**
1. 선택된 노드가 컨테이너 → 그 children에 append
2. 선택된 노드가 leaf → 부모에 sibling으로 추가
3. 선택 없음 → root에 append

**시각 피드백:** 추가된 노드는 _자동 선택_ + 추가 직후 80ms `--dw-motion-fast` 동안 outline pulse (selectable-node outline에 단발 scale 1.05 애니메이션). Claude executor discretion.

- _없음_. 모든 변환은 _프로퍼티 손실 toast_ 로만 표시 — 별도 confirm 모달 없음 (Cmd+Z 로 undo 가능, 기존 history stack 활용).
- _이유:_ Figma/Webflow 모두 type conversion 에 confirm 안 띄움. Toast 만으로 사용자 인지 + undo 보장이면 친화적 UX.

## Motion

기존 `--dw-motion-*` 재사용 + Phase 1 추가 정의:

| Token | Value | Phase 1 사용처 |
|-------|-------|---------------|
| `--dw-motion-fast` | 80ms | spacing overlay fade-out, quick-add pulse, 단축키 hint badge fade |
| `--dw-motion-base` | 140ms | 컴포넌트 카드 hover scale, 좌측 패널 토글 transition (width animation), 변환 dropdown 진입 |
| `--dw-motion-slow` | 220ms | toast 진입 (이미 chrome 표준) |
| `--dw-motion-ease` | `cubic-bezier(0.2, 0, 0, 1)` | 모든 transition timing function |

**Reduced motion:** `globals.css` 의 `@media (prefers-reduced-motion: reduce)` 가 entrance keyframes를 무력화 — Phase 1 새 애니메이션도 이 규칙 _자동 적용_ 위해 `dw-fade-in` / `dw-fade-up` 키프레임 재사용 권장. quick-add pulse 등 transform 애니메이션은 `prefers-reduced-motion` 시 opacity-only fallback.

## Accessibility (WCAG 2.1 AA)

| Concern | Decision |
|---------|----------|
| 키보드 네비게이션 | 좌측 패널 카드 `tabindex="0"` + Enter/Space로 add (drag 대체 경로). 변환 dropdown은 arrow keys 네비. |

| 색상 대비 | accent `#6366f1` on `#0d0e10` dark bg → contrast 5.8:1 (PASS AA). px 라벨 `#ffffff` on `#6366f1` → contrast 4.7:1 (PASS AA). 정렬 가이드 핑크 `#FF8FAB` 는 _시각 보조_ 로 카운트, 콘텐츠 정보 전달 아님 (라벨 항상 별도 px overlay로 제공). |
| Focus visible | 기존 `--dw-focus-ring` 사용. 컴포넌트 카드, 변환 dropdown, 좌측 패널 토글 모두 적용. |
| Screen reader | 박스 선택 종료 시 `aria-live="polite"` 영역에 `"{N}개 노드 선택"` 알림. 정렬/분포 실행 시 `"좌측 정렬"`, `"가로 균등 분포"` 등 알림. |
| 한국어 입력 | `<html lang="ko">` 고정. 모든 한국어 라벨 폰트 fallback 보장 (Pretendard Variable 이 한/영/숫자 모두 커버). |
